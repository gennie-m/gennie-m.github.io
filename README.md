# Gennie Mansi, PhD — Portfolio

A static, single-page portfolio site (plain HTML/CSS, no build step).

## Files

- `index.html` — the whole site (styles inline)
- `assets/` — headshot and project figures

## Publish on GitHub Pages

1. Create a repository (for a personal site named `gennie-mansi.github.io`, the repo must use that exact name).
2. Upload `index.html` and the `assets/` folder to the repository root.
3. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. The site goes live at `https://<username>.github.io/<repo>/` within a minute or two.

To preview locally, open `index.html` in a browser.
